# Red-Dead-Redemption-2

# 🤠 Red Dead Redemption

Site desenvolvido como atividade do curso de Desenvolvimento de Sistemas do SENAI.

## 📚 Sobre o projeto

O projeto apresenta informações sobre o universo de Red Dead Redemption,
utilizando HTML e CSS para criar uma interface inspirada no Velho Oeste.

## 🖥️ Tecnologias utilizadas

- HTML5
- CSS3
- CSS Grid

## 📄 Páginas

- Página inicial
- Personagens
- O mundo de Red Dead Redemption
- Informações sobre o jogo

## 🎯 Objetivo

Praticar os conhecimentos de HTML e CSS, incluindo:

- Estruturação de páginas
- Utilização de imagens
- Links e navegação entre páginas
- CSS Grid
- Organização de elementos
- Estilização com CSS

## 🎓 Projeto acadêmico
